# Blended Learning — Grade 10 Research Project

An interactive educational website for the research project “Blended Learning: Combining Classroom Lessons with Online Platforms — Is It the Most Effective Way?” by Alikhan Kabidenov (10 “Б”, MMGI, Abai Region, Kazakhstan, 2026; supervisor Bulanbayev Serik Zhenisbekuly).

## Tech
TanStack Start (React 19, TypeScript), Tailwind CSS 4, shadcn/ui, lucide-react, Netlify Database (Drizzle ORM) for survey responses, deployed on Netlify.

## Run locally
```bash
pnpm install
netlify dev   # or: npm run dev
```
